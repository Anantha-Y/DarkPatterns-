## 📖 Overview

**Dark patterns** are deceptive UI/UX designs deliberately crafted to trick users into taking actions they did not intend — such as subscribing to paid services, sharing personal data, or making unplanned purchases.

This system provides:

- ✅ **Automated detection** of dark pattern text using a trained ML classifier
- ✅ **Category identification** (Scarcity, Urgency, Social Proof, Misdirection, Obstruction, Sneaking)
- ✅ **Visual analytics** with 5 charts showing dataset and model insights
- ✅ **Interactive web app** built with Streamlit for live text prediction
- ✅ **Business recommendations** to help organisations eliminate dark patterns
- ✅ **Automated project report** generated as a formatted `.docx` file

## ▶️ How to Run

### ⭐ Option A — Single combined file (recommended)

Run the entire pipeline (load → clean → analyse → train → KPIs → charts) with one command:

```bash
python complete_code.py
```

Then launch the app:

```bash
streamlit run Y.Anantha_darkpatterns_app.py --server.port 8502
```

---

### Option B — Individual scripts (step by step)

Run the steps **in order**:

### Step 1 — Load, clean & analyse data

```bash
python Y.Anantha_darkpatterns_analysis.py
```

**Output:**
- Prints dataset shape, column names, first 5 rows
- Cleans missing values, duplicates, invalid labels
- Saves `data/cleaned_darkpatterns.csv`
- Saves `charts/category_bar.png` and `charts/label_pie.png`

---

### Step 2 — Train & evaluate ML models

```bash
python Y.Anantha_darkpatterns_model.py
```

**Output:**
- Trains Logistic Regression and Naive Bayes on TF-IDF features
- Prints accuracy, precision, recall, F1-score for each model
- Saves `models/best_model.pkl` and `models/tfidf_vectorizer.pkl`
- Saves `charts/model_accuracy.png` and `charts/confusion_matrix.png`

---

### Step 3 — Calculate KPIs

```bash
python Y.Anantha_darkpatterns_kpis.py
```

**Output:**
- Computes 3 KPI groups: Data Quality, Model, Business
- Saves all values to `kpis.json`
- KPI cards appear on the Streamlit Home page automatically

---

### Step 4 — Launch the Streamlit web app

```bash
streamlit run Y.Anantha_darkpatterns_app.py --server.port 8502
```

Open in your browser:

| URL | Access |

| **http://localhost:8502** | Local machine |
| **http://192.168.1.5:8502** | Other devices on same Wi-Fi |

## 💡 Business Insights

Five recommendations derived from the analysis:

1. **Replace Scarcity Tricks with Real Inventory Data** — Scarcity is the #1 dark pattern (35.5%); show only verified stock levels.
2. **Eliminate Fake Urgency** — Urgency patterns inflate short-term conversions but increase cart abandonment long-term.
3. **Audit Social Proof Claims** — Fabricated popularity signals are flagged by regulators under the EU Digital Services Act.
4. **Simplify Cancellation Flows** — Apply the "one-click-in, one-click-out" principle to reduce regulatory risk.
5. **Automate Dark Pattern Scanning in CI/CD** — Embed this classifier as a content linting step before production deploys.
